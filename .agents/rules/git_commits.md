# Git Commit Guidelines

- **Atomic Commits**: Cada commit deve ser feito por alteração específica (granular / atômico) para garantir auditoria limpa e rastreabilidade, e nunca agrupar todas as alterações em um único commit.
- **Conventional Commits**: Utilize convenções como `feat:`, `fix:`, `style:`, `refactor:`, `chore:`, etc.
- **Auditoria**: Mantenha mensagens descritivas do motivo e impacto da alteração.
